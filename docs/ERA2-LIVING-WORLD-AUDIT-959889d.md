### 1. BLOCKING — The last unacknowledged memory capture cannot retry on its own

The bridge filters out all previously claimed keys and returns immediately when that leaves an empty batch. The withheld-submit path has already added all the episode's keys to `book.claimed`. A second call for that witness with `submit=true` does nothing if no fresh record arrives. A failed canonical commit after claiming has the same retry problem. The recovery gate gets unstuck by committing **another witness with new keys**. In a quiet world, the final episode can remain pending indefinitely. ### 4. BLOCKING — Valid locomotion inputs can stall the tick or move a walker off its route

`Route::new` accepts any positive finite stride length. Phase wrapping repeatedly subtracts `1.0f32`. For example, a valid stride of 2⁻³⁰ and a distance of one give a phase of 2³⁰. Subtracting one rounds back to the same float, so the tick never returns. Separately, the 16-crossing guard promises to drop excess distance. It exits with the unconsumed distance still in the state, then extrapolates from the next leg by that whole distance. Collision rollback also restores the pre-step distance without restoring the leg index if a crossing already occurred. ## Verdict and three highest-value corrections

**Hold Era-2 sign-off.** The audio synthesis corrective has a clear audible rationale, and the overhead rain-band correction has a clear geometric rationale. The owner's visual judgment and the green lavapipe run answer different questions. The most valuable next packages are:

1. **Recover actual NPC memories and make retries self-sufficient.** Cover the final dropped acknowledgment, full cold reopen, and identical retained records across a dormancy round trip (1–3).
2. **Bound the ordinary NPC tick and its memory use.** Eliminate the nonterminating stride case and route overrun, remove the production wake log's unbounded growth, and measure attributable host allocations across real capacity boundaries (4–5).
3. **Establish a real ground contact and a trustworthy reflected pixel before building puddles.** Fix the landing plane and lifetime together, correct billboard orientation and transparent draw order, then verify camera-correct signed displacement and visible RGB. Implement the authored puddles against those controls and return natural-intensity visual acceptance to the owner (12–15, 18–19).
