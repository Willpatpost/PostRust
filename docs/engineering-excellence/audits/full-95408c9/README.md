## Reading the evidence

Paths in the subsystem records are relative to the repository root unless a crate prefix is stated. A source finding identifies a reachable path, a consequence, a proposed correction and an acceptance test. A design obligation calls for measurement or an owner decision. Passing an ordinary success-path test establishes only the behavior it exercises.
